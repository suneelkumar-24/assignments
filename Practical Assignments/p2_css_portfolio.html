LEVEL 2: HTML + CSS

Level 2.2: Multi-Page Corporate Portfolio

Master CSS Grid, CSS Variables (Dark/Light themes), and glassmorphism styling.

🎯 Project Objective

Construct a multi-page site (Home, Projects, About, Contact) using CSS Grid layouts and custom design tokens.

Requirements Checklist:

  • Define root CSS variables for primary color, background colors, and font sizes (:root { --primary: #38bdf8; }).
  • Build a responsive grid of project items using grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));.
  • Apply glassmorphism effects using backdrop-filter: blur(10px); background: rgba(30, 41, 59, 0.7);.
  • Style custom contact form controls with active focus outlines and glowing effects.

💻 Starter CSS Code Guide

:root { --bg-main: #0f172a; --card-bg: rgba(30, 41, 59, 0.8); --primary-glow: #38bdf8; } .portfolio-grid { display: grid; grid-template-columns: repeat(auto-fill, minmax(280px, 1fr)); gap: 1.5rem; }
