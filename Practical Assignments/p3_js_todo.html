Level 3.2: Smart Task & Habit Planner

Master LocalStorage state persistence, array filtering, and DOM creation methods.

🎯 Project Objective

Build a full task management app that saves data locally in the browser so tasks persist across page refreshes.

Requirements Checklist:

  • Add new tasks with title, category, and priority level.
  • Persist the array in browser memory using localStorage.setItem('tasks', JSON.stringify(tasks)).
  • Load saved tasks on app launch using JSON.parse(localStorage.getItem('tasks')).
  • Support filter tabs: All, Active, Completed tasks.
  • Delete items with smooth fade-out DOM removal.

💻 Starter JS Code Guide

let tasks = JSON.parse(localStorage.getItem("my_tasks")) || []; function saveAndRender() { localStorage.setItem("my_tasks", JSON.stringify(tasks)); renderTasks(); } function addTask(title) { tasks.push({ id: Date.now(), title, completed: false }); saveAndRender(); }
