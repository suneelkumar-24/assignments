LEVEL 1: PURE HTML

Level 1.1: Personal Resume & Profile Page

Learn HTML document structure, headings, semantic tags, lists, images, and anchors.

🎯 Project Objective

Create a structured personal resume web page using purely semantic HTML5 elements without any CSS styling.

Requirements Checklist:

  • Use semantic structural elements: <header>, <main>, <section>, <footer>.
  • Include your full name as <h1> and job title/tagline as <h2>.
  • Add a profile image using <img> with appropriate alt attribute.
  • List your technical skills using an unordered list (<ul>).
  • List your educational background in chronological order using an ordered list (<ol>).
  • Provide contact links (email mailto, phone tel, LinkedIn URL) using <a> tags.

💻 Starter HTML Code Guide

<!DOCTYPE html> <html lang="en"> <head> <meta charset="UTF-8"> <title>My Resume</title> </head> <body> <header> <h1>John Doe</h1> <p>Aspiring Web Developer</p> </header> <main> <section> <h2>About Me</h2> <p>Passionate about creating clean code...</p> </section> <section> <h2>Skills</h2> <ul> <li>HTML5 Semantics</li> <li>Web Accessibility</li> </ul> </section> </main> </body> </html>
