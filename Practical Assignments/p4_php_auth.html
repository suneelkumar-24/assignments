Level 4.2: Secure Auth & Session Management System

Learn PHP sessions, login validation, password hashing, cookies, and protected user routes.

🎯 Project Objective

Implement a complete user login, signup, and protected dashboard area using PHP sessions.

Requirements Checklist:

  • Start sessions at the very top of pages using session_start().
  • Hash passwords during registration using password_hash($pass, PASSWORD_BCRYPT).
  • Verify credentials upon login using password_verify($input_pass, $stored_hash).
  • Store user identity in session global: $_SESSION['user_id'] = $user['id'];.
  • Protect private pages: check if isset($_SESSION['user_id']), else redirect with header("Location: login.php").
  • Implement logout functionality that destroys session cookies: session_destroy().

💻 Starter PHP Code Guide

<?php session_start(); if (isset($_POST['login'])) { $email = $_POST['email']; $password = $_POST['password']; // Simulate user verification if ($email === "student@domain.com" && $password === "secret123") { $_SESSION['user'] = "Student User"; header("Location: dashboard.php"); exit(); } else { $error = "Invalid credentials"; } } ?>
