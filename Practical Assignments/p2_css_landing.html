LEVEL 2: HTML + CSS

Level 2.1: Product Showcase Landing Page

Combine semantic HTML with CSS Flexbox, custom color schemes, gradients, and buttons.

🎯 Project Objective

Style an HTML page into a sleek product landing page using external or internal CSS.

Requirements Checklist:

  • Build a header with a flexbox navigation bar (display: flex; justify-content: space-between;).
  • Create a hero section with a linear background gradient and call-to-action (CTA) buttons.
  • Design 3 product feature cards using Flexbox or CSS Grid layout.
  • Add subtle CSS hover effects (transform: translateY(-5px); transition: all 0.3s ease;).
  • Use Google Fonts (e.g. Outfit, Inter, or Roboto) instead of browser defaults.

💻 Starter CSS Code Guide

/* Flexbox Navbar Header */ .navbar { display: flex; justify-content: space-between; align-items: center; padding: 1rem 2rem; background-color: #1e293b; } /* Card Hover Animation */ .card { transition: transform 0.3s ease, box-shadow 0.3s ease; } .card:hover { transform: translateY(-8px); box-shadow: 0 10px 25px rgba(56, 189, 248, 0.3); }
