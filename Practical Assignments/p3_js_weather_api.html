Level 3.3: Weather & Currency REST API App

Master Promises, Async/Await, fetch(), JSON parsing, and handling loading states.

🎯 Project Objective

Fetch live weather or currency exchange data from an open public REST API and display dynamic results.

Requirements Checklist:

  • Use async/await and fetch(url) to retrieve data asynchronously.
  • Handle HTTP errors (404, 500) gracefully using try...catch blocks and display user alert toasts.
  • Show a visual loading spinner while waiting for API responses.
  • Parse JSON response data and extract temperature, humidity, weather icons, or currency conversion rates.

💻 Starter JS Code Guide

async function fetchWeather(city) { try { const res = await fetch(`https://api.openweathermap.org/data/2.5/weather?q=${city}&units=metric&appid=YOUR_KEY`); if (!res.ok) throw new Error("City not found"); const data = await res.json(); document.getElementById("temp").textContent = `${data.main.temp}°C`; } catch (err) { alert(err.message); } }
