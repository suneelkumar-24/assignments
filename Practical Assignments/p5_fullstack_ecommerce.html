Level 5.2: Complete E-Commerce Store & Admin Panel

Build a full-fledged E-Commerce store with dynamic catalog, shopping cart, user checkout, and admin panel.

🎯 Project Objective

Develop a complete web shop where customers browse products, manage shopping cart, place orders, and admins manage inventory.

Requirements Checklist:

  • Design MySQL tables: users, products, orders, order_items.
  • Dynamic product listing page with price sorting, search bar, and category filters.
  • Active shopping cart stored in PHP session ($_SESSION['cart']) or database.
  • Order checkout flow: summary, shipping details form, and invoice creation.
  • Role-Based Access Control (RBAC): User vs Admin dashboard.
  • Admin inventory control panel: Add new products with file image upload, update prices, manage order statuses.
