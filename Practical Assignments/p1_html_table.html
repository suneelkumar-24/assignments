LEVEL 1: PURE HTML

Level 1.3: Course Timetable & Fee Structure Table

Master HTML tables, table headers, rows, cells, colspans, and rowspans.

🎯 Project Objective

Design a structured timetable and course fee breakdown using advanced HTML table features.

Requirements Checklist:

  • Use proper table markup: <table>, <thead>, <tbody>, <tfoot>.
  • Define column headers using <th>.
  • Merge multiple columns using colspan (e.g. for Lunch Break or Total Fee row).
  • Merge multiple rows using rowspan (e.g. for multi-hour lab sessions).
  • Add a table caption using <caption> tag.

💻 Starter HTML Code Guide

<table border="1"> <caption>Weekly Class Schedule</caption> <thead> <tr> <th>Day</th> <th>9:00 AM - 11:00 AM</th> <th>11:00 AM - 1:00 PM</th> </tr> </thead> <tbody> <tr> <td>Monday</td> <td>HTML Fundamentals</td> <td rowspan="2">Practical Lab</td> </tr> <tr> <td>Tuesday</td> <td>Form Design</td> </tr> </tbody> </table>
