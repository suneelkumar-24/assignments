LEVEL 4: HTML + CSS + JS + PHP

Level 4.1: Dynamic Student Portal & File Uploader

Learn server-side request processing, GET/POST form submissions, and file upload handling in PHP.

🎯 Project Objective

Create a server-rendered student submission form using PHP backend scripts.

Requirements Checklist:

  • Configure <form action="upload.php" method="POST" enctype="multipart/form-data">.
  • Process incoming POST data using PHP global superglobals ($_POST, $_FILES).
  • Validate file extensions (e.g., PDF, PNG, JPG) and file size limits (max 2MB).
  • Move uploaded files securely to an uploads/ directory using move_uploaded_file().
  • Sanitize input strings using htmlspecialchars() to prevent Cross-Site Scripting (XSS).

💻 Starter PHP Code Guide

<?php if ($_SERVER["REQUEST_METHOD"] == "POST") { $student_name = htmlspecialchars($_POST['student_name']); if (isset($_FILES['assignment']) && $_FILES['assignment']['error'] == 0) { $fileName = $_FILES['assignment']['name']; $fileTmp = $_FILES['assignment']['tmp_name']; $targetDir = "uploads/" . basename($fileName); if (move_uploaded_file($fileTmp, $targetDir)) { echo "Assignment submitted successfully for " . $student_name; } } } ?>
