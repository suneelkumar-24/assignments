LEVEL 1: PURE HTML

Level 1.2: Student Admission & Course Form

Master HTML forms, inputs, fieldsets, legends, validation attributes, and labels.

🎯 Project Objective

Build a complete online student registration form using native HTML form elements and attributes.

Requirements Checklist:

  • Group related form sections with <fieldset> and <legend> (Personal Info, Academic Details).
  • Use appropriate input types: text, email, tel, date, file, number.
  • Implement gender choice using radio buttons (type="radio") with matching name attributes.
  • Include multi-choice subjects using checkboxes (type="checkbox").
  • Add a course selection dropdown using <select> and <option>.
  • Enforce required fields using required, minlength, and pattern.

💻 Starter HTML Code Guide

<form action="#" method="POST"> <fieldset> <legend>Personal Details</legend> <label for="fullname">Full Name:</label> <input type="text" id="fullname" name="fullname" required minlength="3"> <label for="email">Email Address:</label> <input type="email" id="email" name="email" required> <label>Gender:</label> <input type="radio" id="male" name="gender" value="male"> <label for="male">Male</label> <input type="radio" id="female" name="gender" value="female"> <label for="female">Female</label> </fieldset> <button type="submit">Submit Application</button> </form>
