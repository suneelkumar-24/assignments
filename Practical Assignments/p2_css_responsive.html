LEVEL 2: HTML + CSS

Level 2.3: Responsive Layout & Media Queries

Master mobile-first responsive design, breakpoints, and fluid typography.

🎯 Project Objective

Create a layout that adapts seamlessly across mobile (320px+), tablet (768px+), and desktop (1024px+) viewports.

Requirements Checklist:

  • Set up viewports correctly using <meta name="viewport" content="width=device-width, initial-scale=1.0">.
  • Write media queries for key breakpoints: @media (max-width: 768px) and @media (min-width: 1024px).
  • Convert desktop navbar links into a hamburger icon drawer for mobile views.
  • Make images responsive using max-width: 100%; height: auto;.

💻 Starter CSS Code Guide

/* Mobile First Styles */ .container { padding: 1rem; } .nav-menu { display: none; } /* Tablet & Desktop Breakpoint */ @media (min-width: 768px) { .container { padding: 2rem; } .nav-menu { display: flex; gap: 1rem; } }
