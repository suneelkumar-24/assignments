Level 3.1: Interactive Quiz & Grade Calculator

Combine structure, design, and JavaScript DOM manipulation, logic, arrays, and events.

🎯 Project Objective

Create an interactive Quiz app where questions are rendered dynamically from a JavaScript array of objects.

Requirements Checklist:

  • Store questions, choices, and correct answers in a JavaScript array of objects (questions = [{q: '...', options: [...], ans: 0}]).
  • Use DOM selection (document.querySelector, getElementById) to update UI dynamically on option select.
  • Compute total score, accuracy percentage, and letter grade when user clicks Submit.
  • Add countdown timer using setInterval() that automatically submits when time expires.
