Topic 10

CSS Introduction & Selectors

Foundational

CSS (Cascading Style Sheets) decorates and arranges HTML elements. Styles can be applied Inline (in the style attribute), Internal (in <style> tags), or External (linked .css file). Selectors target elements via Tag, Class (.class), ID (#id), Universal (*), or Attribute ([type="email"]).

Code Example: CSS Selector Types
selectors.css 
/* 1. Universal Selector */
* { box-sizing: border-box; margin: 0; padding: 0; }

/* 2. Element / Tag Selector */
h1 { color: #f8fafc; font-size: 2rem; }

/* 3. Class Selector (Reusable) */
.btn-primary { background: #0284c7; color: #fff; padding: 10px 20px; border-radius: 8px; }

/* 4. ID Selector (Unique) */
#heroSection { background: #0f172a; padding: 60px 20px; }

/* 5. Attribute Selector */
input[type="email"] { border: 1px solid #38bdf8; padding: 8px; }
💡
Mukesh Sir's Pro Tip: Always use External CSS stylesheets via <link rel="stylesheet" href="style.css"> in production. External sheets are cached by the browser on first load, cutting page load time in half!
Topic 11

Colors, Backgrounds & Gradients

Color Theory

Colors can be specified with HEX (#38bdf8), RGB (rgb(56, 189, 248)), or HSL (hsl(199, 95%, 60%)). Backgrounds support images, cover/contain sizing, fixed parallax attachments, and smooth linear/radial gradients.

Code Example: Modern Gradients & Background Styling
backgrounds.css 
.card-gradient {
  /* Linear Gradient Angle and Color Stops */
  background: linear-gradient(135deg, #0284c7 0%, #38bdf8 50%, #0369a1 100%);
  color: #ffffff;
  padding: 30px;
  border-radius: 16px;
}

.hero-banner {
  /* High-Res Background Image with Dark Gradient Overlay */
  background: linear-gradient(rgba(15, 23, 42, 0.8), rgba(15, 23, 42, 0.9)), url('banner.jpg');
  background-size: cover;
  background-position: center;
  background-repeat: no-repeat;
  min-height: 400px;
}
💡
Mukesh Sir's Pro Tip: Layering a semi-transparent gradient on top of background images (linear-gradient(rgba(0,0,0,0.6), rgba(0,0,0,0.6)), url(...)) guarantees that white text remains 100% readable regardless of how bright the photo is!
Topic 12

Borders, Radius & Outlines

Borders

Borders occupy physical space in the layout (shorthand: width style color). border-radius curves the corners. Unlike borders, outline is drawn outside the element and takes up zero layout space, making it perfect for accessible focus rings.

Code Example: Border Radius & Glow Outlines
borders.css 
.pill-badge {
  border: 1.5px solid #38bdf8;
  border-radius: 50px; /* Fully rounded pill */
  padding: 6px 14px;
}

.input-field:focus-visible {
  outline: 2px solid #38bdf8;
  outline-offset: 3px; /* Air gap between input and outline */
  border-color: #0284c7;
}

.glow-card {
  border: 1px solid rgba(56, 189, 248, 0.3);
  border-radius: 16px;
  box-shadow: 0 4px 20px rgba(56, 189, 248, 0.25);
}
💡
Mukesh Sir's Pro Tip: Never remove outline: none on interactive inputs without providing an alternative :focus-visible style. Removing focus outlines completely ruins navigation for keyboard users!
Topic 13

Spacing: Margins & Paddings

Spacing

padding creates breathing space inside the element's border. margin creates clearance outside the border between neighboring elements. Vertical margins on block elements collapse into a single margin equal to the largest value.

Code Example: 4-Value Clockwise Notation & Centering
spacing.css 
/* Clockwise Shorthand: Top, Right, Bottom, Left */
.box {
  padding: 10px 20px 15px 25px;
}

/* 2-Value Shorthand: Vertical (Top/Bottom), Horizontal (Left/Right) */
.container {
  padding: 24px 16px;
  margin: 0 auto; /* Horizontally centers block element */
  max-width: 1200px;
}
💡
Mukesh Sir's Pro Tip: To center any block element (like .container or .card), you MUST give it an explicit width or max-width along with margin: 0 auto;.
Topic 14

Dimensions (Min / Max Width & Height)

Layout

Fixed widths (e.g. width: 800px;) cause horizontal overflow on mobile phones. Responsive layouts use relative percentages combined with max-width to allow shrinking on small viewports while capping on large desktop screens.

Code Example: Fluid Width with Boundaries
dimensions.css 
.responsive-content {
  width: 100%;
  max-width: 960px; /* Never exceeds 960px on wide monitors */
  min-height: 350px; /* Expands if text content grows longer */
  margin: 0 auto;
}
💡
Mukesh Sir's Pro Tip: Avoid setting rigid fixed height on text containers. Use min-height instead, so if font sizes increase or lines wrap on small phones, the container can expand naturally without clipping text!
Topic 15

The CSS Box Model & Box Sizing

Core Rule

Every HTML element consists of four layers: Content → Padding → Border → Margin. Under the default box-sizing: content-box, adding padding increases the element's overall rendered width. Setting box-sizing: border-box absorbs padding and borders inside the declared width.

Code Example: Global Border-Box Reset
box_model.css 
/* Universal Box-Sizing Reset */
*, *::before, *::after {
  box-sizing: border-box;
}

.box {
  width: 300px;
  padding: 20px;
  border: 5px solid #38bdf8;
  /* With border-box, total rendered width stays exactly 300px! */
}
💡
Mukesh Sir's Pro Tip: Always declare *, *::before, *::after { box-sizing: border-box; } on line 1 of every project stylesheet. This single rule eliminates 90% of layout misalignment bugs in web development!

Topic 16

Display: Block, Inline & Inline-Block

Flow

block takes 100% full width and starts on a new line. inline only takes the width of its text and ignores top/bottom margins. inline-block sits side-by-side on the same line like an inline element, but respects widths, heights, and vertical margins!

Code Example: Display Comparison
display.css 
.nav-item {
  display: inline-block;
  padding: 8px 16px;
  margin-right: 10px;
  background: #1e293b;
  border-radius: 6px;
}

.hidden-element {
  display: none; /* Completely removed from document layout */
}
💡
Mukesh Sir's Pro Tip: display: inline-block elements will have an automatic 4px invisible whitespace gap between them caused by the carriage return in HTML. Remove the HTML space or switch to modern Flexbox to eliminate it!
Topic 17

Visibility: Hidden vs Display: None

Rendering

display: none removes the element entirely from the DOM layout flow as if it never existed. visibility: hidden makes the element invisible, but preserves its exact width and height space in the page flow! opacity: 0 allows smooth transitions while remaining clickable.

Code Example: Visibility vs Display
visibility.css 
/* 1. Gone completely (surrounding elements shift) */
.drawer.closed { display: none; }

/* 2. Invisible, but leaves an empty ghost space */
.skeleton-placeholder { visibility: hidden; }

/* 3. Invisible but animatable (pointer-events: none disables clicks) */
.tooltip {
  opacity: 0;
  pointer-events: none;
  transition: opacity 0.3s ease;
}
.parent:hover .tooltip {
  opacity: 1;
  pointer-events: auto;
}
💡
Mukesh Sir's Pro Tip: You cannot animate or transition display: none to display: block in CSS. To create smooth fades or slide menus, use opacity and transform with pointer-events: none!
Topic 18

Fonts & Typography (Google Fonts)

Typography

Professional web typography relies on Google Fonts or system font stacks. Use font-family with fallbacks, font-size in scalable rem units, font-weight (400 regular, 700 bold), and line-height: 1.6 for effortless readability.

Code Example: Modern Typography Stack
typography.css 
body {
  font-family: 'Plus Jakarta Sans', system-ui, -apple-system, sans-serif;
  font-size: 1rem; /* 16px default browser baseline */
  line-height: 1.65;
  color: #f8fafc;
  letter-spacing: -0.2px;
}

code, pre {
  font-family: 'Fira Code', monospace;
}
💡
Mukesh Sir's Pro Tip: Always specify line-height without units (e.g. line-height: 1.6; instead of 1.6rem). Unitless line-height scales proportionately whenever child elements change their font size!
Topic 19

Icons & Vector Masking

Assets

Modern UI utilizes vector SVGs or icon libraries (Bootstrap Icons, Lucide, Font Awesome). SVGs scale infinitely to retina displays without pixelation and inherit colors via currentColor.

Code Example: CurrentColor Vector Icon Styling
icons.css 
.icon {
  width: 20px;
  height: 20px;
  stroke: currentColor;
  fill: none;
  vertical-align: middle;
  transition: transform 0.2s ease;
}

.btn:hover .icon {
  transform: translateX(4px);
}
💡
Mukesh Sir's Pro Tip: Setting stroke: currentColor; on SVGs automatically synchronizes the icon color with the parent element's text color. When hovering over buttons, the icon color changes automatically with zero extra CSS!
Topic 20

Links & Interactive Pseudo-Classes

Interactivity

Pseudo-classes style elements based on user interaction states. The required order of link pseudo-classes is LVHA: :link → :visited → :hover → :active.

Code Example: Animated Hover Underline
links.css 
.nav-link {
  color: #94a3b8;
  text-decoration: none;
  position: relative;
  transition: color 0.2s ease;
}

.nav-link:hover {
  color: #38bdf8;
}

.nav-link::after {
  content: "";
  position: absolute;
  bottom: -4px;
  left: 0;
  width: 0%;
  height: 2px;
  background: #38bdf8;
  transition: width 0.3s cubic-bezier(0.4, 0, 0.2, 1);
}

.nav-link:hover::after {
  width: 100%;
}
💡
Mukesh Sir's Pro Tip: Remember the mnemonic: "Lord Vader Handles Anakin" for :link, :visited, :hover, :active. Violating this order causes CSS cascade rules to overwrite your hover styles!
Topic 21

Lists Styling & Custom Markers

Lists

Remove default bullets using list-style: none;. Use the modern ::marker pseudo-element to color bullets independently, or build custom badges using CSS counters.

Code Example: Custom Gradient Numbered Steps
lists.css 
.step-list {
  list-style: none;
  counter-reset: step-counter;
}

.step-list li {
  counter-increment: step-counter;
  position: relative;
  padding-left: 45px;
  margin-bottom: 16px;
}

.step-list li::before {
  content: counter(step-counter);
  position: absolute;
  left: 0;
  top: 0;
  width: 30px;
  height: 30px;
  background: #0284c7;
  color: #fff;
  border-radius: 50%;
  display: flex;
  align-items: center;
  justify-content: center;
  font-weight: bold;
}
💡
Mukesh Sir's Pro Tip: Using counter-reset and counter-increment allows you to create stylized circle badges that count sequentially even if you reorder or insert new list items dynamically!
Topic 22

Table Styling & Sticky Headers

Tables

Always use border-collapse: collapse; to merge double borders into crisp single lines. Add zebra striping with :nth-child(even), hover highlights, and sticky column headers.

Code Example: Modern Zebra Table with Sticky Header
tables.css 
.data-table {
  width: 100%;
  border-collapse: collapse;
  font-size: 0.9rem;
}

.data-table th {
  background: #1e293b;
  color: #38bdf8;
  position: sticky;
  top: 0;
  padding: 12px 16px;
  text-align: left;
}

.data-table td {
  padding: 12px 16px;
  border-bottom: 1px solid #1e3a6e;
}

.data-table tbody tr:nth-child(even) {
  background: rgba(255, 255, 255, 0.02);
}

.data-table tbody tr:hover {
  background: rgba(56, 189, 248, 0.08);
}
💡
Mukesh Sir's Pro Tip: To make tables responsive on smartphones without shrinking fonts to an unreadable size, wrap the <table> in a <div style="overflow-x: auto; -webkit-overflow-scrolling: touch;"> container!

Topic 23

CSS Specificity & The Cascade

Cascade

When multiple rules target the same element, the browser calculates specificity scores: Inline styles (1000) > IDs (100) > Classes, attributes & pseudo-classes (10) > Elements (1). !important overrides the cascade, but causes unmaintainable code if overused.

Code Example: Specificity Calculation
specificity.css 
/* Score: 0, 0, 0, 1 (Lowest) */
button { background: gray; }

/* Score: 0, 0, 1, 0 (Wins over tag) */
.btn { background: blue; }

/* Score: 0, 0, 2, 0 */
.navbar .btn { background: navy; }

/* Score: 0, 1, 0, 0 (High specificity) */
#mainSubmit { background: green; }
💡
Mukesh Sir's Pro Tip: Never use !important to fix specificity bugs in production. Instead, keep your selectors flat by writing single class names (BEM methodology: .card__title), keeping specificity predictable!
Topic 24

Pseudo-Elements (::before & ::after)

Pseudo-Elements

::before and ::after insert decorative cosmetic content without adding extra HTML tags. They require a declared content: ""; property and are commonly used for ribbons, overlays, and background effects.

Code Example: Glassmorphism Gradient Overlay
pseudo.css 
.featured-card {
  position: relative;
  overflow: hidden;
  background: #1e293b;
  padding: 30px;
}

/* Decorative corner glow without HTML tags */
.featured-card::before {
  content: "";
  position: absolute;
  top: -40px;
  right: -40px;
  width: 120px;
  height: 120px;
  background: radial-gradient(circle, #38bdf8 0%, transparent 70%);
  border-radius: 50%;
  pointer-events: none;
}
💡
Mukesh Sir's Pro Tip: Pseudo-elements will fail to render if you forget the content: ""; property! Even if the content is completely empty, the property must be present.
Topic 25

Positioning: Relative, Absolute, Fixed & Sticky

Positioning

relative keeps original document space and acts as an anchor for absolute children. absolute removes element from flow, positioning against the nearest non-static parent. fixed anchors to the viewport. sticky toggles between relative and fixed based on scroll position!

Code Example: Sticky Sidebar & Absolute Badges
position.css 
/* Anchor Container */
.product-card {
  position: relative;
  padding: 20px;
}

/* Absolute Corner Tag */
.discount-badge {
  position: absolute;
  top: 12px;
  right: 12px;
  background: #ef4444;
  color: #fff;
  padding: 4px 8px;
}

/* Sticky Header / Sidebar */
.sticky-nav {
  position: sticky;
  top: 0;
  z-index: 1000;
}
💡
Mukesh Sir's Pro Tip: position: sticky will silently break if any ancestor element in the DOM tree has overflow: hidden or overflow-x: hidden. Always use overflow-x: clip on the body to prevent sticky breakage!
Topic 26

Overflow Handling & Text Truncation

Overflow

overflow: hidden crops content outside boundaries. overflow: auto injects scrollbars only when content exceeds boundaries. Single-line text truncation requires white-space: nowrap; overflow: hidden; text-overflow: ellipsis;.

Code Example: Single & Multi-Line Truncation
overflow.css 
/* 1-Line Truncation with Ellipsis (...) */
.truncate-single {
  white-space: nowrap;
  overflow: hidden;
  text-overflow: ellipsis;
  max-width: 250px;
}

/* 2-Line Clamp with Native CSS */
.truncate-multiline {
  display: -webkit-box;
  -webkit-line-clamp: 2;
  -webkit-box-orient: vertical;
  overflow: hidden;
}
💡
Mukesh Sir's Pro Tip: The -webkit-line-clamp: 2 property is officially standardized across all modern browsers, enabling clean paragraph card excerpts without writing custom truncation scripts!
Topic 27

CSS Custom Properties (Variables) & Theming

Variables

CSS variables are declared using --variable-name inside :root and accessed using var(--variable-name). They cascade through child components and enable dark/light theme switching with a single class change!

Code Example: Dark / Light Mode Theming System
variables.css 
:root {
  --bg-color: #0f172a;
  --card-bg: #1e293b;
  --text-color: #f8fafc;
  --primary-accent: #38bdf8;
}

body.light-theme {
  --bg-color: #f8fafc;
  --card-bg: #ffffff;
  --text-color: #0f172a;
  --primary-accent: #0284c7;
}

.card {
  background: var(--card-bg);
  color: var(--text-color);
  border: 1px solid var(--primary-accent);
}
💡
Mukesh Sir's Pro Tip: CSS variables are reactive at runtime! When you change a CSS variable via JavaScript (document.documentElement.style.setProperty('--primary-accent', '#10b981')), every component on the page updates instantly without a page refresh!

Topic 28

Floats & The Modern Clearfix

Floats

float causes text to wrap around images. However, floating elements collapse parent container heights. The modern micro-clearfix restores parent container bounds.

Code Example: Clearfix Implementation
floats.css 
.article-image {
  float: left;
  margin: 0 18px 12px 0;
}

/* Micro Clearfix on Parent */
.clearfix::after {
  content: "";
  display: table;
  clear: both;
}
💡
Mukesh Sir's Pro Tip: Never use floats to build website layouts in modern development! Floats are strictly reserved for wrapping text around images. All page layouts should be built with Flexbox or Grid.
Topic 29

2D & 3D CSS Transforms

Transforms

Transforms modify coordinate geometry without triggering layout repaints: translate() moves elements, rotate() turns them, and scale() zooms them. Adding perspective creates authentic 3D spatial depth!

Code Example: GPU-Accelerated Hover Lift
transforms.css 
.card {
  transition: transform 0.3s cubic-bezier(0.4, 0, 0.2, 1);
  will-change: transform;
}

.card:hover {
  /* GPU-Accelerated Lift & Zoom */
  transform: translateY(-8px) scale(1.02);
}
💡
Mukesh Sir's Pro Tip: Always animate transform and opacity instead of animating top, left, width, or height. Transforms run directly on the graphics card GPU at a silky-smooth 60 frames per second!
Topic 30

CSS Transitions & Timing Functions

Transitions

Transitions smoothly interpolate property changes between states. Shorthand: property duration timing-function delay. Cubic-bezier curves provide realistic physics (ease-out, spring effects).

Code Example: Smooth Button State Transition
transitions.css 
.btn-magic {
  background: #0284c7;
  color: #fff;
  transition: background-color 0.25s ease, box-shadow 0.25s ease, transform 0.25s cubic-bezier(0.4, 0, 0.2, 1);
}

.btn-magic:hover {
  background: #38bdf8;
  transform: translateY(-2px);
  box-shadow: 0 8px 25px rgba(56, 189, 248, 0.4);
}
💡
Mukesh Sir's Pro Tip: Avoid writing transition: all 0.3s;. Explicitly list the exact properties being transitioned (e.g. background, transform) to prevent performance lag on mobile CPUs.
Topic 31

Keyframe Animations (@keyframes)

Animations

@keyframes defines multi-step animation sequences over time (from 0% to 100%). Properties include animation-name, duration, iteration-count: infinite, and animation-direction: alternate.

Code Example: Pulse Glow Keyframe Animation
animations.css 
@keyframes pulseGlow {
  0% {
    transform: scale(1);
    box-shadow: 0 0 0 0 rgba(56, 189, 248, 0.5);
  }
  70% {
    transform: scale(1.05);
    box-shadow: 0 0 0 15px rgba(56, 189, 248, 0);
  }
  100% {
    transform: scale(1);
    box-shadow: 0 0 0 0 rgba(56, 189, 248, 0);
  }
}

.live-indicator {
  width: 12px;
  height: 12px;
  background: #38bdf8;
  border-radius: 50%;
  animation: pulseGlow 2s infinite cubic-bezier(0.4, 0, 0.6, 1);
}
💡
Mukesh Sir's Pro Tip: Always respect user accessibility preferences with @media (prefers-reduced-motion: reduce). Users with vestibular disorders can experience nausea from continuous animations, so disable animations when requested!
Topic 32

Media Queries & Mobile-First Responsive Design

RWD

Media queries apply different CSS rules depending on viewport width. In Mobile-First design, default styles target smartphones, while @media (min-width: ...) progressively enhances the layout for tablets and desktops.

Code Example: Mobile-First Responsive Grid
responsive.css 
/* 1. Base Mobile Default (1 Column) */
.card-grid {
  display: grid;
  grid-template-columns: 1fr;
  gap: 16px;
}

/* 2. Tablet Viewport (2 Columns) */
@media (min-width: 640px) {
  .card-grid { grid-template-columns: repeat(2, 1fr); }
}

/* 3. Desktop Viewport (3 Columns) */
@media (min-width: 1024px) {
  .card-grid { grid-template-columns: repeat(3, 1fr); }
}
💡
Mukesh Sir's Pro Tip: Standard industry breakpoints: 640px (Tablets), 768px (iPad), 1024px (Laptops), and 1280px (Desktops). Designing mobile-first ensures faster load times for 80% of mobile web users!

Topic 33

Flexbox: The Complete Guide

Flexbox

Flexbox is a 1-dimensional layout model for rows or columns. Main Axis alignment is handled by justify-content, Cross Axis by align-items. Flex items resize via flex-grow, flex-shrink, and flex-basis.

Code Example: Perfect Centering & Auto-Spacing
flexbox.css 
/* 1. Holy Grail Perfect Center in 3 Lines */
.center-box {
  display: flex;
  justify-content: center; /* Horizontally centered */
  align-items: center;     /* Vertically centered */
}

/* 2. Responsive Navigation Bar */
.navbar {
  display: flex;
  justify-content: space-between; /* Spreads brand and links to opposite ends */
  align-items: center;
  gap: 15px;
  flex-wrap: wrap; /* Wraps neatly on small phones */
}
💡
Mukesh Sir's Pro Tip: Use gap: 15px; in Flexbox instead of adding margins to child items! The gap property only places space between siblings, completely eliminating messy :last-child { margin-right: 0 } hacks!
Topic 34

CSS Grid: Complete 2D Grid Guide

CSS Grid

CSS Grid is a 2-dimensional system handling columns and rows simultaneously. Use repeat(auto-fit, minmax(280px, 1fr)) to create auto-responsive grids without writing a single media query!

Code Example: Zero-Media-Query Responsive Auto-Grid
grid.css 
.auto-card-grid {
  display: grid;
  /* Automatically wraps from 1 to 4 columns based on available width! */
  grid-template-columns: repeat(auto-fit, minmax(260px, 1fr));
  gap: 20px;
}
💡
Mukesh Sir's Pro Tip: repeat(auto-fit, minmax(260px, 1fr)) calculates the exact maximum number of columns that can fit on screen. If viewport is 300px, it shows 1 column; if 1200px, it shows 4 columns automatically!
Topic 35

Modern CSS Functions (clamp, aspect-ratio & filters)

Modern CSS

Modern CSS eliminates JavaScript workarounds: clamp(min, preferred, max) enables fluid typography, aspect-ratio: 16 / 9 guarantees video proportions, and backdrop-filter: blur(12px) renders native glassmorphism!

Code Example: Fluid Typography & Frosted Glass
modern_functions.css 
/* 1. Fluid Font: Never smaller than 1.5rem, scales with 4vw, never exceeds 3rem */
h1 {
  font-size: clamp(1.5rem, 4vw, 3rem);
}

/* 2. Frosted Glassmorphism Container */
.glass-panel {
  background: rgba(255, 255, 255, 0.08);
  border: 1px solid rgba(255, 255, 255, 0.15);
  backdrop-filter: blur(14px);
  border-radius: 20px;
}

/* 3. Auto Aspect Ratio */
.video-thumbnail {
  aspect-ratio: 16 / 9;
  object-fit: cover;
}
💡
Mukesh Sir's Pro Tip: With clamp(), you no longer need 5 different media queries to tweak heading font sizes for mobile, tablet, and desktop. A single line scales smoothly across all viewports!

Project 01

💎 Responsive Glassmorphic SaaS Landing Page

Glassmorphism

A high-end SaaS product hero layout with frosted glass containers, multi-color ambient blurred radial orbs, gradient call-to-action buttons, and fully fluid responsive grids.

glass_landing.css 
/* Frosted Glass Hero Container */
.glass-hero {

  overflow: hidden;
}

/* Ambient Radial Glow Orb */
.glass-hero::before {
  content: "";
  position: absolute;
  top: -60px;
  left: -60px;
  width: 250px;
  height: 250px;
  background: radial-gradient(circle, rgba(56, 189, 248, 0.45) 0%, transparent 70%);
  border-radius: 50%;
  pointer-events: none;
}

.hero-cta {
  background: linear-gradient(135deg, #0284c7, #38bdf8);
  color: #fff;

🔄 3D Interactive Flipping Portfolio Cards (Perspective)

3D Transforms

A 3-dimensional card flip component utilizing CSS perspective, transform-style: preserve-3d, and backface-visibility: hidden for interactive front/back bio cards.

flip_card_3d.css 
/* 1. Perspective Viewport Container */
.flip-card-container {
  perspective: 1000px;
  width: 300px;
  height: 400px;
}

.flip-card-inner {
  position: relative;
  width: 100%;
  height: 100%;

  transform-style: preserve-3d;
}

}

Mukesh Sir's Architecture Tip: backface-visibility: hidden tells the browser not to draw the back side of the card when flipped away from the camera. This is the secret to creating seamless two-sided flipping business cards in CSS!
