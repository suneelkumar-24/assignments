Topic 36

JS Introduction, Internal/External & DevTools

Foundational

JavaScript is a lightweight, interpreted, just-in-time compiled language with first-class functions. Code runs in the browser or Node.js. Use browser DevTools (F12) for console.log(), console.table(), and debugging.

Code Example: Console Methods & DevTools

// 1. Standard Output

const students = [
  { id: 101, name: "Mukesh Kumar", track: "Full Stack" },

console.table(students);

// 3. Execution Benchmarking
console.time("Loop Timer");

console.timeEnd("Loop Timer");

Mukesh Sir's Pro Tip: Always link your external script at the very bottom of the <body> tag or use <script src="app.js" defer></script> in the <head> so HTML elements parse completely before your JS runs!
Topic 37

Variables: var, let & const (Scope Rules)

Variables

var is function-scoped and hoisted with undefined. ES6 introduced let (re-assignable block-scoped) and const (immutable reference block-scoped) which remain in the Temporal Dead Zone (TDZ) until initialized.

Code Example: Block Scope vs Function Scope
variables.js 
const INSTITUTE_NAME = "Super Sys-Tech Computers"; // Cannot be reassigned
let activeBatch = 2026; // Can be updated later
activeBatch = 2027; // Valid

if (true) {
  let blockVariable = "I live only inside this block {}";
  var leakedVariable = "I leak outside this block!";
}
// console.log(blockVariable); // ReferenceError: blockVariable is not defined
console.log(leakedVariable);   // Outputs: "I leak outside this block!"
💡
Mukesh Sir's Pro Tip: Golden Rule: Use const by default for 90% of variables. Only use let if you know the value will be reassigned in loops or accumulators. Never use var in modern code!
Topic 38

Data Types: Primitive vs Reference

Types

JavaScript has 7 Primitive Types (String, Number, BigInt, Boolean, Undefined, Null, Symbol) stored by value on the Call Stack, and Reference Types (Objects, Arrays, Functions) stored by memory address pointer on the Memory Heap.

Code Example: Primitives vs Memory References
data_types.js 
// 1. Primitive: Copied by Value
let a = 10;
let b = a;
b = 25;
console.log(a); // Still 10!

// 2. Reference Type: Copied by Memory Pointer
const userA = { name: "Mukesh" };
const userB = userA; // Both point to the exact same object in memory!
userB.name = "Suneel";
console.log(userA.name); // Changed to "Suneel"!
💡
Mukesh Sir's Pro Tip: Notice that typeof null returns "object". This is a famous historical bug in the initial 1995 JavaScript engine implementation that was kept for backward compatibility!
Topic 39

Operators: Strict Equality (===) & Nullish Coalescing (??)

Operators

Always use Strict Equality === (compares both value and type) over Loose Equality == (performs implicit type coercion). Use the Nullish Coalescing operator ?? to supply default values only when an operand is null or undefined.

Code Example: Equality & Modern Fallback Operators
operators.js 
// Loose vs Strict
console.log(5 == "5");   // true (type coercion)
console.log(5 === "5");  // false (different types!)

// Nullish Coalescing (??) vs Logical OR (||)
let score = 0; // 0 is a valid score!
let resA = score || 50; // Returns 50 because 0 is falsy! (Bug)
let resB = score ?? 50; // Returns 0 because 0 is not null/undefined! (Correct)
💡
Mukesh Sir's Pro Tip: Use ?? instead of || when setting default values for numeric or boolean settings, because 0 and false will be mistakenly overwritten by ||!

Strict Mode

Code Example: Strict Mode Enforcement

Topic 41

Conditional Statements (if, else if, else)

Control Flow

Conditionals execute code blocks based on truthy or falsy boolean evaluations. In JavaScript, exactly six values are falsy: false, 0, "" (empty string), null, undefined, and NaN. Everything else evaluates to truthy!

Code Example: Grade Classification Logic
grading.js 
function calculateGrade(percentage) {
  if (percentage >= 80) {
    return "A-1 Grade (Distinction)";
  } else if (percentage >= 70) {
    return "A Grade";
  } else if (percentage >= 60) {
    return "B Grade";
  } else if (percentage >= 50) {
    return "C Grade";
  } else {
    return "Fail (Re-appear for exam)";
  }
}

console.log(calculateGrade(84)); // A-1 Grade (Distinction)
💡
Mukesh Sir's Pro Tip: Remember that empty arrays [] and empty objects {} are truthy in JavaScript! To check if an array is empty, always check arr.length === 0!
Topic 42

Switch-Case Statements & Fallthrough

Switch

switch checks an expression against multiple matching case clauses using strict equality (===). Omitting the break; statement causes execution to fall through to the next case automatically.

Code Example: Course Fee Lookup with Fallthrough
switch_case.js 
function getCourseDetails(code) {
  switch (code.toUpperCase()) {
    case "HTML":
    case "CSS":
      return "Frontend Core Track • 1.5 Months • Rs. 4,000";
    case "JS":
      return "JavaScript ES6 & DOM Masterclass • 2 Months • Rs. 5,000";
    case "PHP":
      return "PHP 8 & MySQL PDO Backend • 2.5 Months • Rs. 6,000";
    default:
      return "Course code not found. Contact Sys-Tech Umerkot Desk.";
  }
}

console.log(getCourseDetails("js"));
💡
Mukesh Sir's Pro Tip: Grouping multiple cases together before a single return/break statement (as with HTML and CSS above) creates clean, readable multi-value routing logic!
Topic 43

Loops: for, while & do-while

Iteration

Loops repeat code execution. for loops are ideal when iteration counts are known. while loops run as long as a condition holds true. do-while is guaranteed to execute at least once before testing the condition.

Code Example: Loop Control with Break & Continue
loops.js 
// Print only even numbers up to 10, skip 6
for (let i = 2; i <= 10; i += 2) {
  if (i === 6) {
    continue; // Skips current iteration
  }
  console.log("Even Number:", i);
}
💡
Mukesh Sir's Pro Tip: Always verify that your while loop condition has an incrementer (e.g. count++). Forgetting to update the variable creates an infinite loop that freezes the browser tab!
Topic 44

Modern Iteration: for...in vs for...of

Loops

for...in iterates over enumerable property keys of an object. for...of iterates over the values of iterable collections (Arrays, Strings, Sets, Maps, NodeLists).

Code Example: for...in vs for...of Comparison
for_of.js 
// 1. for...in on Object Keys
const student = { name: "Mukesh Kumar", rollNo: "STC-2026", city: "Umerkot" };
for (const key in student) {
  console.log(`${key}: ${student[key]}`);
}

// 2. for...of on Array Values
const languages = ["HTML5", "CSS3", "JavaScript", "PHP"];
for (const lang of languages) {
  console.log("Mastering:", lang);
}
💡
Mukesh Sir's Pro Tip: Never use for...in on Arrays! for...in treats array indices as strings and also iterates over prototype properties, which can cause unexpected bugs!

Topic 45

Functions & Default Parameters

Functions

Functions encapsulate reusable logic. Function declarations are hoisted to the top of their scope, while function expressions are not. ES6 allows default parameters for clean fallbacks.

Code Example: Function with Default Parameters
functions.js 
function generateReceipt(studentName, course = "Full Stack Web", fee = 5000) {
  return `Receipt for ${studentName} | Course: ${course} | Total: Rs. ${fee.toLocaleString()}`;
}

console.log(generateReceipt("Mukesh Kumar")); 
// Output: Receipt for Mukesh Kumar | Course: Full Stack Web | Total: Rs. 5,000
💡
Mukesh Sir's Pro Tip: Default parameters only trigger when an argument is undefined. Passing null will NOT trigger the default value!
Topic 46

Arrow Functions & Lexical `this`

ES6 Arrow

Arrow functions (=>) provide concise syntax and omit the function keyword. Crucially, arrow functions do NOT bind their own this; they inherit this lexically from their surrounding scope!

Code Example: Arrow Functions & Lexical Scope
arrow_functions.js 
// 1. One-line implicit return
const calculateTax = amount => amount * 0.13;

// 2. Lexical this preservation in timer callbacks
const counterApp = {
  count: 0,
  start() {
    setInterval(() => {
      this.count++; // 'this' points directly to counterApp!
      // In regular functions, 'this' would point to window!
    }, 1000);
  }
};
💡
Mukesh Sir's Pro Tip: Never use an arrow function as an object method (e.g. const obj = { getTitle: () => this.title }) because this will point to the global window object rather than obj!
Topic 47

Scope Chain & Practical Closures

Closures

A closure is the combination of a function bundled together with references to its surrounding state (the lexical environment). A closure gives an inner function access to an outer function's scope even after the outer function has returned!

Code Example: Private State with Closures
closures.js 
function createBankAccount(initialDeposit) {
  let balance = initialDeposit; // Private variable hidden from outside world!

  return {
    deposit(amount) { balance += amount; return balance; },
    withdraw(amount) { balance -= amount; return balance; },
    getBalance() { return balance; }
  };
}

const account = createBankAccount(10000);
account.deposit(2500);
console.log(account.getBalance()); // 12500
// account.balance is undefined! Direct tampering is impossible!
💡
Mukesh Sir's Pro Tip: Closures are the foundation of data privacy in JavaScript! They allow you to create completely private state variables without needing TypeScript private class fields.

Math Object & Random Number Generators

Math

Topic 52

Array Manipulation Methods

Arrays

Arrays store ordered collections. Mutating methods include push()/pop() (end) and unshift()/shift() (start). splice() modifies in-place, while slice() extracts a pure shallow copy.

Code Example: Splice vs Slice
arrays.js 
const courses = ["HTML", "CSS", "Bootstrap", "JavaScript", "PHP"];

// Non-destructive slice (extracts items 1 through 3 without mutating original)
const frontend = courses.slice(0, 4); 

// Destructive splice (removes 1 item at index 2 and inserts "Tailwind")
courses.splice(2, 1, "Tailwind CSS");

console.log(courses); // ["HTML", "CSS", "Tailwind CSS", "JavaScript", "PHP"]
💡
Mukesh Sir's Pro Tip: In modern React and state management paradigms, always avoid mutating arrays directly with splice. Prefer non-destructive methods like slice, filter, or the spread operator ([...arr])!
Topic 53

Higher-Order Iterators (map, filter & reduce)

Functional JS

Higher-order methods take callback functions. map() transforms every element into a new array. filter() selects items that pass a test condition. reduce() accumulates items into a single final value.

Code Example: Chained Functional Data Pipeline
iterators.js 
const studentRegistrations = [
  { name: "Mukesh", paidFee: 5000, active: true },
  { name: "Kavita", paidFee: 4500, active: false },
  { name: "Suresh", paidFee: 6000, active: true }
];

// Chained Pipeline: Filter active students -> Calculate total fee collected
const totalRevenue = studentRegistrations
  .filter(s => s.active)
  .reduce((sum, s) => sum + s.paidFee, 0);

console.log("Total Center Fee Collected: Rs.", totalRevenue); // 11000
💡
Mukesh Sir's Pro Tip: Always specify an initial value (like 0 above) as the second argument to reduce() to avoid runtime errors when iterating over empty arrays!

Objects, Methods & Object Utilities

Objects

Objects store key-value pairs and functions (methods). Access properties with dot notation (obj.prop) or bracket notation (obj["prop"]). Extract entries using Object.keys(), Object.values(), and Object.entries().

const centerConfig = {

Topic 55

Destructuring & Spread / Rest Operators (...)

ES6 Syntax

Destructuring unpacks values from arrays or properties from objects into distinct variables. The spread operator (...) expands iterables, while the rest parameter condenses multiple arguments into an array.

Code Example: Destructuring & Immutable Object Merging
destructuring.js 
// 1. Object Destructuring with Aliasing & Defaults
const student = { fullName: "Mukesh Kumar", roll: 104 };
const { fullName: name, roll, city = "Umerkot" } = student;

// 2. Spread Operator: Immutable Clone & Merge
const baseProfile = { role: "Student", active: true };
const completeRecord = { ...baseProfile, name, roll, city };

// 3. Rest Operator in Functions
function sumMarks(...marks) {
  return marks.reduce((total, m) => total + m, 0);
}
console.log(sumMarks(85, 92, 78, 90)); // 345
💡
Mukesh Sir's Pro Tip: Using const clone = { ...original } creates a shallow copy. If your object contains nested objects, mutate cautiously or use structuredClone(original) for a deep copy!

Topic 56

DOM Tree Architecture & Node Hierarchy

DOM Core

The Document Object Model represents an HTML document as a hierarchical tree of nodes. Every HTML tag is an Element Node, text is a Text Node, and attributes are Attribute Nodes. The global document object is your entry point.

Code Example: Navigating DOM Parents & Children
dom_tree.js 
const card = document.querySelector(".topic-card");

console.log("Parent Element:", card.parentElement);
console.log("Child Elements:", card.children); // HTMLCollection of direct element tags
console.log("Next Sibling:", card.nextElementSibling);
💡
Mukesh Sir's Pro Tip: Always use children and nextElementSibling rather than childNodes and nextSibling. Sibling nodes include invisible whitespace and line-break text nodes!
Topic 57

DOM Selectors: querySelector & querySelectorAll

Selectors

document.querySelector() returns the first matching element using any CSS selector. document.querySelectorAll() returns a static NodeList containing all matching elements, which supports .forEach()!

Code Example: Selecting and Batch-Styling Nodes
selectors.js 
// 1. Single Element Selection
const submitBtn = document.querySelector("#submitBtn");

// 2. Multi-Element Selection & Iteration
const badges = document.querySelectorAll(".sidebar-item.active");
badges.forEach(badge => {
  badge.style.fontWeight = "bold";
});
💡
Mukesh Sir's Pro Tip: querySelectorAll returns a NodeList, not an Array. If you need methods like .map() or .filter(), convert it using Array.from(document.querySelectorAll(...))!

Creating, Appending & Removing DOM Nodes

Topic 61

Event Listeners, Bubbling & Event Delegation

Events bubble upwards through the DOM hierarchy from target to parent. Event Delegation leverages this bubbling behavior by attaching a single listener to a parent container to manage clicks on hundreds of dynamically generated children!

// Single listener handles deletes for all present and future 
  •  buttons!

  if (e.target.matches(".delete-btn")) {
    const row = e.target.closest("li");
    row.remove();
  }
});
    • 💡

    Topic 64

    Timers: setTimeout & setInterval

    Timers

    setTimeout() executes a callback once after a delay in milliseconds. setInterval() repeats execution indefinitely until cleared with clearInterval() using its unique timer ID.

    Code Example: Accurate Countdown Exam Timer
    timers.js 
    let timeLeft = 60; // 60 seconds

const timerId = setInterval(() => {
  timeLeft--;
  console.log("Exam Time Remaining:", timeLeft, "seconds");

  if (timeLeft <= 0) {
    clearInterval(timerId); // Stop timer
    alert("Exam time is up! Submitting answers automatically.");
  }
}, 1000);
    💡
    Mukesh Sir's Pro Tip: Always store the return value of setInterval() in a variable so you can pass it to clearInterval(). Forgetting this will cause background timers to leak and waste user device battery!
    Topic 65

    Web Storage API: localStorage & sessionStorage

    Storage

    localStorage persists up to 5MB of data in the browser with no expiration date. sessionStorage clears when the browser tab is closed. Storage only holds strings, so serialize objects using JSON.stringify() and JSON.parse().

    Code Example: Persisting Complex Objects in LocalStorage
    storage.js 
    // 1. Save complex array of objects to LocalStorage
const tasks = [
  { id: 1, title: "Finish HTML Notes", done: true },
  { id: 2, title: "Practice Flexbox Grid", done: false }
];
localStorage.setItem("stc_student_tasks", JSON.stringify(tasks));

// 2. Retrieve and parse back into JavaScript Objects
const savedTasks = JSON.parse(localStorage.getItem("stc_student_tasks")) || [];
console.log("Retrieved Tasks:", savedTasks);
    💡
    Mukesh Sir's Pro Tip: Always pair JSON.parse() with a fallback: JSON.parse(localStorage.getItem(...) || "[]"). If the key doesn't exist yet, it safely initializes an empty array instead of throwing a null parsing error!
    Topic 66

    Asynchronous JS: Async / Await & Fetch API

    Async / Await

    Modern async JavaScript uses Promises with clean async/await syntax. The native fetch() API requests data over HTTP. Always wrap asynchronous requests inside try...catch blocks to handle network disconnects gracefully.

    Code Example: Robust Async Fetch API with Error Handling
    async_fetch.js 
    async function fetchWeatherData(city) {
  try {
    const response = await fetch(`https://api.example.com/weather?q=${city}`);
    
    // Fetch does NOT reject on HTTP 404 or 500 errors! Check response.ok manually:
    if (!response.ok) {
      throw new Error(`HTTP Error Status: ${response.status}`);
    }

    const data = await response.json();
    console.log("Weather in", city, data);
    return data;
  } catch (error) {
    console.error("Network or API Failure:", error.message);
  }
}
    💡
    Mukesh Sir's Pro Tip: A critical gotcha with fetch() is that it will only reject if there is a network breakdown. If the server returns a 404 (Not Found) or 500 (Internal Error), fetch resolves normally! You must always check if (!response.ok)!

    this.filter = "all";
    this.listEl = document.querySelector("#todoList");
    this.formEl = document.querySelector("#todoForm");
    this.inputEl = document.querySelector("#todoInput");
    this.init();
  }

  init() {
    this.formEl.addEventListener("submit", (e) => {
      e.preventDefault();
      const title = this.inputEl.value.trim();
      if (!title) return;
      this.tasks.push({ id: Date.now(), title, completed: false });
      this.inputEl.value = "";
      this.saveAndRender();
    });

    this.listEl.addEventListener("click", (e) => {
      const id = Number(e.target.closest("li")?.dataset.id);
      if (e.target.matches(".toggle-btn")) {
        const task = this.tasks.find(t => t.id === id);
        if (task) task.completed = !task.completed;
        this.saveAndRender();
      } else if (e.target.matches(".delete-btn")) {
        this.tasks = this.tasks.filter(t => t.id !== id);
        this.saveAndRender();
      }
    });

    this.render();
  }

  saveAndRender() {
    localStorage.setItem("stc_todos", JSON.stringify(this.tasks));
    this.render();
  }

  render() {
    const filtered = this.tasks.filter(t => {
      if (this.filter === "active") return !t.completed;
      if (this.filter === "completed") return t.completed;
      return true;
    });

    this.listEl.innerHTML = filtered.map(t => `
      <li data-id="${t.id}" class="${t.completed ? 'completed' : ''}">
        <span class="toggle-btn">${t.completed ? '☑' : '☐'}</span>
        <span class="title">${t.title}</span>
        <button class="delete-btn">×</button>
      </li>
    `).join("");
  }
}

new TodoApp();
    💡
    Mukesh Sir's Architecture Tip: Using data-id="${t.id}" with Date.now() guarantees unique IDs for every record. Event delegation via e.target.closest("li") cleanly identifies which item was clicked without needing closures inside loops!

    💰 Financial Loan EMI & Tuition Installment Calculator

    Math & Inputs

    A real-time financial installment calculator utilizing compound interest formulas, interactive input sliders (<input type="range">), and dynamic monthly breakdown graphs.

    emi_calculator.js 
    function calculateEMI() {
  const principal = parseFloat(document.querySelector("#loanAmount").value);
  const annualRate = parseFloat(document.querySelector("#interestRate").value);
  const tenureMonths = parseFloat(document.querySelector("#tenureMonths").value);

  // Monthly Interest Rate
  const monthlyRate = annualRate / 12 / 100;

  // Standard EMI Formula: [P * R * (1+R)^N] / [(1+R)^N - 1]
  const emi = (principal * monthlyRate * Math.pow(1 + monthlyRate, tenureMonths)) / 
              (Math.pow(1 + monthlyRate, tenureMonths) - 1);

  const totalPayment = emi * tenureMonths;
  const totalInterest = totalPayment - principal;

  document.querySelector("#monthlyEmiDisplay").textContent = `Rs. ${Math.round(emi).toLocaleString()}`;
  document.querySelector("#totalInterestDisplay").textContent = `Rs. ${Math.round(totalInterest).toLocaleString()}`;
  document.querySelector("#totalPayableDisplay").textContent = `Rs. ${Math.round(totalPayment).toLocaleString()}`;
}

// Attach live input listeners to all range sliders
document.querySelectorAll(".calc-slider").forEach(slider => {
  slider.addEventListener("input", (e) => {
    // Synchronize slider number label
    document.querySelector(`#${e.target.id}Val`).textContent = e.target.value;
    calculateEMI();
  });
});

calculateEMI();
    💡
    Mukesh Sir's Architecture Tip: Using the Math.pow(base, exponent) mathematical function ensures precision when computing exponential compound rates across multi-year amortization schedules!
