Topic 67

PHP Introduction, Server Execution & Tags

Beginner

PHP stands for Hypertext Preprocessor. It is an open-source, server-side scripting language. Unlike HTML and JavaScript which run in the client's browser, PHP executes directly on the web server (such as Apache in XAMPP). The server compiles the PHP code and returns pure HTML to the user's browser, keeping backend code completely secure.

Key Concepts & Syntax Rules
  • Standard Opening & Closing tags: <?php ... ?>
  • Every PHP statement must terminate with a semicolon (;).
  • Files must be saved with a .php extension in your web root (e.g. C:/xampp/htdocs/).
  • PHP is case-sensitive for variable names ($name != $Name), but keywords (echo, if, while) are case-insensitive.
Practical Code Example (Embedded in HTML)
example_67.php 
<!-- Embedded PHP inside HTML -->
<!DOCTYPE html>
<html>
<body>
    <h1><?php echo "Welcome to Super Sys-Tech Computers Centre!"; ?></h1>
    <p>Today's Date is: <?php echo date("l, F j, Y"); ?></p>
</body>
</html>
Expected Browser Output:

Welcome to Super Sys-Tech Computers Centre!

Today's Date is: Thursday, September 3, 2026

💡
Mukesh Sir's Pro Tip: Never try to open a .php file by double-clicking it on your Desktop! Browsers cannot execute PHP directly. Always start Apache in XAMPP, place your file in htdocs, and visit http://localhost/your_folder/filename.php.
Topic 68

Output Methods: echo, print, print_r & var_dump

Beginner

PHP provides multiple ways to print content. Beginners often wonder which one to use. echo and print output strings and numbers, whereas print_r() and var_dump() are essential for debugging complex arrays and objects.

Differences at a Glance
  • echo: Language construct, takes multiple arguments separated by commas, slightly faster, has no return value.
  • print: Language construct, takes only one argument, always returns 1 (can be used in expressions).
  • print_r(): Formats and displays human-readable arrays and objects.
  • var_dump(): Displays the value, length, AND exact data type (great for debugging).
Practical Code Example
example_68.php 
<?php
$student = "Mukesh Kumar";
$age = 22;
$scores = [85, 92, 78];

// 1. Using echo
echo "Student: " . $student . " | Age: " . $age . "<br>";

// 2. Using print
print("Enrolled at Super Sys-Tech Computers<br>");

// 3. Using print_r for array
echo "<pre>";
print_r($scores);
echo "</pre>";

// 4. Using var_dump for debugging data types
var_dump($age); // outputs int(22)
?>
Expected Browser Output: Student: Mukesh Kumar | Age: 22
Enrolled at Super Sys-Tech Computers
Array ( [0] => 85 [1] => 92 [2] => 78 )
int(22)
💡
Mukesh Sir's Pro Tip: Always wrap print_r() and var_dump() inside HTML <pre>...</pre> tags. It retains line breaks and makes nested arrays 10x easier to read during exam tests and project debugging!
Topic 69

Variables, Variable Scope & Constants

Beginner

In PHP, variables are containers for storing information. They are dynamically typed (you don't need to specify int or string). A variable starts with a dollar sign ($) followed by the name. Constants hold values that cannot change during script execution.

Variable Scopes Explained
  • Local Scope: Declared inside a function; accessible only inside that function.
  • Global Scope: Declared outside functions. To access inside a function, use the global keyword or $GLOBALS['var'].
  • Static Scope: When a function finishes, local variables are deleted. Use static to keep their value for next call!
  • Constants: Created using define('NAME', value) or const NAME = value. No $ sign!
Practical Code Example
example_69.php 
<?php
// Defining Constants (Globally accessible anywhere)
define("INSTITUTE_NAME", "Super Sys-Tech Computers Centre");
define("CITY", "Umerkot");

$globalCounter = 100; // Global variable

function trackStudentAttendance() {
    global $globalCounter; // Pull global inside
    static $attendedCount = 0; // Persists between calls!

    $attendedCount++;
    echo "Class Attended: " . $attendedCount . " times | Base: " . $globalCounter . "<br>";
}

echo "Welcome to " . INSTITUTE_NAME . ", " . CITY . "<br>";
trackStudentAttendance(); // Count: 1
trackStudentAttendance(); // Count: 2
trackStudentAttendance(); // Count: 3
?>
Expected Browser Output: Welcome to Super Sys-Tech Computers Centre, Umerkot
Class Attended: 1 times | Base: 100
Class Attended: 2 times | Base: 100
Class Attended: 3 times | Base: 100
💡
Mukesh Sir's Pro Tip: Remember: In PHP, constants are globally available everywhere—even inside functions—without using the global keyword. Use uppercase names like DB_HOST or APP_URL by convention.
Topic 70

PHP Data Types & Explicit Type Casting

Beginner

Variables can store data of different types. PHP supports 8 primitive data types divided into three main categories: Scalar (Single value), Compound (Multiple values), and Special.

Data Types Category
  • String: Text enclosed in quotes: "Mukesh" or 'Kumar'.
  • Integer: Non-decimal number between -2B and +2B: $age = 24;
  • Float (Double): Numbers with decimal point: $fee = 1500.50;
  • Boolean: true or false.
  • Array: Stores multiple values in one variable: ['HTML', 'CSS', 'PHP'].
  • Object: Instances of programmer-defined classes.
  • NULL: A variable with no value assigned.
  • Type Casting: Convert explicitly using (int), (string), (float), (bool), (array).
Practical Code Example
example_70.php 
<?php
$rawFee = "2500"; // String
$actualFee = (int)$rawFee; // Explicit casting to Integer

$isEnrolled = true; // Boolean
$discount = 12.5;   // Float

var_dump($actualFee); // int(2500)
var_dump($isEnrolled); // bool(true)
var_dump($discount); // float(12.5)
?>
Expected Browser Output: int(2500)
bool(true)
float(12.5)
💡
Mukesh Sir's Pro Tip: Double quotes (" ") parse variables and escape sequences like \n. Single quotes (' ') output plain literal text without evaluating variables. For better performance, use single quotes when variable evaluation is not required!
Topic 71

Operators, Expressions & Comparison (== vs ===)

Beginner

Operators perform mathematical, comparative, and logical calculations on variables and values. PHP includes modern operators like the Null Coalescing Operator (??) and the Spaceship Operator (<=>).

Crucial Operator Summary
  • String Concatenation: Use dot (.) in PHP, NOT plus (+)!
  • Loose Equality (==): Compares value only, performs automatic type conversion ("10" == 10 is TRUE).
  • Strict Equality (===): Compares value AND data type ("10" === 10 is FALSE).
  • Null Coalescing (??): Returns fallback if null: $user = $_GET['name'] ?? 'Guest';
  • Ternary (? :): Shorthand if-else: $status = ($marks >= 50) ? 'Pass' : 'Fail';
Practical Code Example
example_71.php 
<?php
$val1 = 100;
$val2 = "100";

echo ($val1 == $val2) ? "== is TRUE (Values match)<br>" : "FALSE<br>";
echo ($val1 === $val2) ? "=== is TRUE" : "=== is FALSE (Types differ: int vs string)<br>";

// Modern Null Coalescing operator
$username = null;
$displayName = $username ?? "Guest Student";
echo "Logged in as: " . $displayName;
?>
Expected Browser Output: == is TRUE (Values match)
=== is FALSE (Types differ: int vs string)
Logged in as: Guest Student
💡
Mukesh Sir's Pro Tip: Always use === (triple equals) for login checks, token checks, and password verifications to prevent PHP loose type-juggling vulnerabilities.

Topic 73

Switch Statement vs Modern PHP 8 match Expression

Intermediate

When comparing a single variable against many possible values, switch prevents long chains of elseif. PHP 8 introduced the match expression, which is shorter, returns values directly, and performs strict comparisons (===) without requiring break!

Code Example (Role & Course Selector)
example_73.php 
<?php
$courseCode = "FSW";

// 1. Classic Switch statement
switch ($courseCode) {
    case "CIT":
        echo "Certificate in Information Tech<br>";
        break;
    case "FSW":
        echo "Full-Stack Web Development Course<br>";
        break;
    default:
        echo "General Computer Basics<br>";
        break;
}

// 2. Modern PHP 8 match expression
$duration = match ($courseCode) {
    "CIT" => "3 Months",
    "FSW" => "6 Months (Intensive)",
    default => "1 Month",
};

echo "Course Duration: " . $duration;
?>
Expected Browser Output: Full-Stack Web Development Course
Course Duration: 6 Months (Intensive)
💡
Mukesh Sir's Pro Tip: In interviews, examiners frequently ask: "What happens if you forget a break statement in a switch case?" Answer: PHP falls through and executes the next case regardless of whether its condition is met!
Topic 74

Loops in PHP: while, do-while, for & foreach

Beginner to Intermediate

Loops execute a block of code repeatedly until a condition is met. The foreach loop is unique and by far the most widely used loop in PHP because it iterates over arrays seamlessly without requiring manual index tracking.

Loop Types Summary
  • while: Checks condition first, then executes.
  • do-while: Executes once first, then checks condition.
  • for: Initializer, condition, increment in one line. Best for known counts.
  • foreach: Iterates each element in arrays: foreach ($arr as $key => $val).
Code Example (Student Roster Iteration)
example_74.php 
<?php
// Associative array of student roll numbers and names
$students = [
    "STC-101" => "Mukesh Kumar",
    "STC-102" => "Rahul Dev",
    "STC-103" => "Priya Sharma"
];

echo "<h4>Super Sys-Tech Student List:</h4>";
echo "<ul>";

// foreach loop with Key and Value
foreach ($students as $rollNo => $name) {
    echo "<li><strong>" . $rollNo . ":</strong> " . $name . "</li>";
}

echo "</ul>";
?>
Expected Browser Output:

Super Sys-Tech Student List:

  • STC-101: Mukesh Kumar
  • STC-102: Rahul Dev
  • STC-103: Priya Sharma
💡
Mukesh Sir's Pro Tip: Use break to stop and exit a loop immediately when your search target is found. Use continue to skip the current iteration and jump straight to the next cycle!

Topic 80

Superglobal Variables ($_SERVER, $_GET, $_POST, etc.)

Intermediate

Superglobals are built-in global associative arrays provided by PHP. They are automatically accessible anywhere in any file, function, or class without needing global $var.

All 9 Superglobals Explained
  • $_SERVER: Information on server headers, paths, script locations, and IP address.
  • $_GET: Data sent via URL query strings (e.g. ?id=5&name=mukesh).
  • $_POST: Data sent via HTTP POST method (secure for passwords and forms).
  • $_FILES: Items uploaded via multipart forms.
  • $_COOKIE: Variables passed via client browser HTTP cookies.
  • $_SESSION: Variables stored across multiple pages for logged-in users.
  • $_REQUEST: Combined contents of $_GET, $_POST, and $_COOKIE.
  • $_ENV: Environment configuration variables.
  • $GLOBALS: References all global variables available in current script.
Topic 81

Secure Form Handling, Sanitization & Validation

Intermediate

Never trust user input! Malicious users can inject JavaScript (XSS attacks) or malicious SQL code. Before using input, you must sanitize and validate it using htmlspecialchars(), trim(), and filter_var().

Secure PHP Form Script
contact_form.php 
<?php
$message = "";

if ($_SERVER["REQUEST_METHOD"] === "POST") {
    // 1. Sanitize and trim inputs
    $name = htmlspecialchars(trim($_POST["fullName"] ?? ""));
    $email = filter_var(trim($_POST["email"] ?? ""), FILTER_SANITIZE_EMAIL);

    // 2. Validate empty and email format
    if (empty($name)) {
        $message = "Error: Full name is required!";
    } elseif (!filter_var($email, FILTER_VALIDATE_EMAIL)) {
        $message = "Error: Invalid email format!";
    } else {
        $message = "Success: Welcome, " . $name . "! Enrollment recorded.";
    }
}
?>
💡
Mukesh Sir's Pro Tip: Always use htmlspecialchars() whenever echoing user-submitted text back to the browser screen. It converts special characters like < and > into HTML entities (&lt;), blocking Cross-Site Scripting (XSS) completely!

Handling file uploads (e.g. student profile photos, PDF assignments) requires an HTML form with enctype="multipart/form-data" and method POST. On the server, PHP receives the details inside the $_FILES superglobal.

Error Handling & Exceptions (try, catch, finally)

Topic 88

Advanced OOP: Access Modifiers, Inheritance & Method Overriding

Advanced

Inheritance allows a child class to inherit properties and methods from a parent class using extends. Access modifiers control where properties and methods can be accessed.

Access Modifiers Defined
  • public: Accessible from anywhere (inside and outside the class).
  • protected: Accessible only within the class itself and by inheriting child classes.
  • private: Accessible ONLY within the class where it was defined.
Code Example (Inheritance Hierarchy)
inheritance.php 
<?php
// Base Parent Class
class Person {
    protected string $name;

    public function __construct($name) {
        $this->name = $name;
    }

    public function introduce() {
        return "Hello, I am " . $this->name;
    }
}

// Child Class inherits Person
class Instructor extends Person {
    private string $subject;

    public function __construct($name, $subject) {
        parent::__construct($name); // Call parent constructor
        $this->subject = $subject;
    }

    // Method Overriding
    public function introduce() {
        parent::introduce();
        return "Hello, I am {$this->name}, teaching {$this->subject} at Super Sys-Tech!";
    }
}

$sir = new Instructor("Mukesh Kumar", "PHP & MySQL");
echo $sir->introduce();
?>

PDO (PHP Data Objects) is the industry standard database abstraction layer in PHP. Unlike the old mysqli_query(), PDO works across 12 different database types and provides parameterized Prepared Statements that completely neutralize SQL Injection attacks!

pdo_database.php 
<?php
$host = "localhost";
$db   = "stc_student_portal";
$user = "root";
$pass = "";
$charset = "utf8mb4";

$dsn = "mysql:host=$host;dbname=$db;charset=$charset";
$options = [
    PDO::ATTR_ERRMODE            => PDO::ERRMODE_EXCEPTION,
    PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC,
    PDO::ATTR_EMULATE_PREPARES   => false,
];

try {
    // 1. Connect to MySQL
    $pdo = new PDO($dsn, $user, $pass, $options);
    
    // 2. CREATE (Insert student with Prepared Statement)
    $insertSql = "INSERT INTO students (name, email, course) VALUES (:name, :email, :course)";
    $stmt = $pdo->prepare($insertSql);
    $stmt->execute([
        ":name" => "Mukesh Kumar",
        ":email" => "mukesh@supersystech.edu",
        ":course" => "Full-Stack Web"
    ]);

    // 3. READ (Fetch records securely)
    $selectSql = "SELECT id, name, course FROM students WHERE course = :course";
    $queryStmt = $pdo->prepare($selectSql);
    $queryStmt->execute([":course" => "Full-Stack Web"]);
    $studentsList = $queryStmt->fetchAll();

    foreach ($studentsList as $row) {
        echo "ID: {$row['id']} | Name: {$row['name']}<br>";
    }

} catch (PDOException $e) {
    echo "Database Error: " . $e->getMessage();
}
?>

    $pdo = new PDO("mysql:host={$host};dbname={$dbname};charset=utf8mb4", $username, $password, [

        PDO::ATTR_DEFAULT_FETCH_MODE => PDO::FETCH_ASSOC

    exit;
}

try {
    // 3. Begin Transaction (Ensures student & fee records succeed atomically)
    $pdo->beginTransaction();

    // Generate unique official roll number: e.g. STC-2026-4821
    $rollNo = "STC-" . date("Y") . "-" . rand(1000, 9999);

    // Insert student record
    $stmt = $pdo->prepare("INSERT INTO students (roll_no, full_name, class_grade, guardian_phone, enrollment_date) VALUES (?, ?, ?, ?, CURDATE())");
    $stmt->execute([$rollNo, $name, $grade, $phone]);
    $studentId = $pdo->lastInsertId();

    // Insert initial admission fee voucher
    $feeStmt = $pdo->prepare("INSERT INTO fee_payments (student_id, month_name, amount_paid, payment_status) VALUES (?, ?, 2500.00, 'Paid')");
    $feeStmt->execute([$studentId, date("F Y")]);
    $receiptNo = $pdo->lastInsertId();

    // Commit both operations
    $pdo->commit();

    echo json_encode([
        "status"     => "success",
        "roll_no"    => $rollNo,
        "receipt_no" => $receiptNo

USE school_db;

-- 1. Students Table
CREATE TABLE IF NOT EXISTS students (
    id INT AUTO_INCREMENT PRIMARY KEY,
    roll_no VARCHAR(20) UNIQUE NOT NULL,
    full_name VARCHAR(100) NOT NULL,
    class_grade VARCHAR(50) NOT NULL,
    guardian_phone VARCHAR(20) NOT NULL,
    enrollment_date DATE NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
) ENGINE=InnoDB;

-- 2. Fee Payments Ledger Table
CREATE TABLE IF NOT EXISTS fee_payments (
    receipt_no INT AUTO_INCREMENT PRIMARY KEY,
    student_id INT NOT NULL,
    month_name VARCHAR(30) NOT NULL,
    amount_paid DECIMAL(10,2) NOT NULL DEFAULT 2500.00,
    payment_status ENUM('Paid', 'Pending') DEFAULT 'Paid',
    paid_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    FOREIGN KEY (student_id) REFERENCES students(id) ON DELETE CASCADE
) ENGINE=InnoDB;

header('Content-Type: application/json');
$pdo = new PDO("mysql:host=localhost;dbname=library_db;charset=utf8mb4", "root", "", [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]);

$input = json_decode(file_get_contents("php://input"), true);
$loanId = (int)($input['loanId'] ?? 0);
$fineRatePerDay = 20.00; // Rs. 20 per day overdue

try {
    // 1. Fetch loan record and calculate overdue days via MySQL DATEDIFF
    $stmt = $pdo->prepare("SELECT book_id, due_date, DATEDIFF(CURDATE(), due_date) as overdue_days FROM book_loans WHERE id = ? AND return_date IS NULL");
    $stmt->execute([$loanId]);
    $loan = $stmt->fetch(PDO::FETCH_ASSOC);

    if (!$loan) {
        throw new Exception("Active loan record not found or already returned!");
    }

    $overdueDays = max(0, (int)$loan['overdue_days']);
    $fine = $overdueDays * $fineRatePerDay;

    $pdo->beginTransaction();

    // 2. Close loan record and record fine
    $updLoan = $pdo->prepare("UPDATE book_loans SET return_date = CURDATE(), fine_amount = ? WHERE id = ?");
    $updLoan->execute([$fine, $loanId]);

    // 3. Restock library book catalog
    $updBook = $pdo->prepare("UPDATE library_books SET available_copies = available_copies + 1 WHERE id = ?");
    $updBook->execute([$loan['book_id']]);

    $pdo->commit();

    echo json_encode([
        "status"       => "success",
        "overdue_days" => $overdueDays,
        "fine_amount"  => number_format($fine, 2)
    ]);
} catch (Exception $e) {
    if ($pdo->inTransaction()) $pdo->rollBack();
    echo json_encode(["status" => "error", "message" => $e->getMessage()]);
}

$pdo = new PDO("mysql:host=localhost;dbname=store_db;charset=utf8mb4", "root", "", [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]);

$input = json_decode(file_get_contents("php://input"), true);

    echo json_encode(["status" => "error", "message" => "Shopping cart is empty!"]);
    exit;

try {
    $pdo->beginTransaction();
    $orderCode = "ORD-" . strtoupper(uniqid());
    $totalAmount = 0;

    // 1. Create Main Order Record
    $orderStmt = $pdo->prepare("INSERT INTO store_orders (order_code, customer_name, total_amount) VALUES (?, ?, 0)");
    $orderStmt->execute([$orderCode, $customer]);
    $orderId = $pdo->lastInsertId();

    // 2. Decrement inventory with FOR UPDATE row locks to prevent overselling
    foreach ($cart as $id => $item) {
        $qty = (int)$item['qty'];
        $chk = $pdo->prepare("SELECT unit_price, stock_qty FROM store_products WHERE id = ? FOR UPDATE");
        $chk->execute([$id]);
        $product = $chk->fetch(PDO::FETCH_ASSOC);

        if ($product['stock_qty'] < $qty) {
            throw new Exception("Product '{$item['title']}' has insufficient stock!");
        }

        $lineTotal = $product['unit_price'] * $qty;
        $totalAmount += $lineTotal;

        // Insert Line Item
        $itemStmt = $pdo->prepare("INSERT INTO order_items (order_id, product_id, quantity, price) VALUES (?, ?, ?, ?)");
        $itemStmt->execute([$orderId, $id, $qty, $product['unit_price']]);

        // Decrement stock
        $dec = $pdo->prepare("UPDATE store_products SET stock_qty = stock_qty - ? WHERE id = ?");
        $dec->execute([$qty, $id]);
    }

    // 3. Finalize Order Total
    $upd = $pdo->prepare("UPDATE store_orders SET total_amount = ? WHERE id = ?");
    $upd->execute([$totalAmount, $orderId]);

    $pdo->commit();
    echo json_encode(["status" => "success", "order_code" => $orderCode, "total" => number_format($totalAmount, 2)]);
} catch (Exception $e) {
    $pdo->rollBack();
    echo json_encode(["status" => "error", "message" => $e->getMessage()]);
}

Backend Controller: api_process_payroll.php
api_process_payroll.php 
<?php
header('Content-Type: application/json');
$pdo = new PDO("mysql:host=localhost;dbname=hrms_db;charset=utf8mb4", "root", "", [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]);

$input = json_decode(file_get_contents("php://input"), true);
$empId = (int)($input['emp_id'] ?? 0);
$month = trim($input['month'] ?? '');
$daysWorked = min(30, (int)($input['days'] ?? 0));
$otHours = (int)($input['ot_hours'] ?? 0);

try {
    $stmt = $pdo->prepare("SELECT basic_salary FROM employees WHERE id = ?");
    $stmt->execute([$empId]);
    $baseSalary = (float)$stmt->fetchColumn();

    // 1. Calculate Per-Day Pay (30-day corporate standard)
    $perDayRate = $baseSalary / 30;
    $basicEarned = $perDayRate * $daysWorked;

    // 2. Overtime calculation (Rs. 350 per hour)
    $otBonus = $otHours * 350;

    // 3. Tax / Provident Fund deduction (5% flat)
    $deductions = ($basicEarned + $otBonus) * 0.05;
    $netSalary = ($basicEarned + $otBonus) - $deductions;

    // 4. Save audit log
    $ins = $pdo->prepare("INSERT INTO salary_slips (employee_id, payroll_month, days_worked, basic_earned, ot_bonus, deductions, net_salary) VALUES (?, ?, ?, ?, ?, ?, ?)");
    $ins->execute([$empId, $month, $daysWorked, $basicEarned, $otBonus, $deductions, $netSalary]);

    echo json_encode([
        "status"       => "success",
        "basic_earned" => round($basicEarned, 2),
        "ot_bonus"     => $otBonus,
        "deductions"   => round($deductions, 2),
        "net_salary"   => round($netSalary, 2)
    ]);
} catch (Exception $e) {
    echo json_encode(["status" => "error", "message" => $e->getMessage()]);
}
?>

Backend Controller: api_sign_lease.php
api_sign_lease.php 
<?php
header('Content-Type: application/json');
$pdo = new PDO("mysql:host=localhost;dbname=realestate_db;charset=utf8mb4", "root", "", [PDO::ATTR_ERRMODE => PDO::ERRMODE_EXCEPTION]);

$input = json_decode(file_get_contents("php://input"), true);
$propId = (int)($input['property_id'] ?? 0);
$tenant = htmlspecialchars(trim($input['tenant_name'] ?? ''));
$cnic   = htmlspecialchars(trim($input['cnic'] ?? ''));
$months = (int)($input['months'] ?? 11);

try {
    $pdo->beginTransaction();

    // 1. Verify property is Available with Row Lock
    $chk = $pdo->prepare("SELECT monthly_rent, status FROM properties WHERE id = ? FOR UPDATE");
    $chk->execute([$propId]);
    $prop = $chk->fetch(PDO::FETCH_ASSOC);

    if (!$prop || $prop['status'] !== 'Available') {
        throw new Exception("Property is not available for leasing!");
    }

    $rent = $prop['monthly_rent'];
    $securityDeposit = $rent * 2; // 2 months deposit standard
    $leaseCode = "LSE-" . strtoupper(uniqid());

    // 2. Insert Lease Agreement
    $ins = $pdo->prepare("INSERT INTO rental_leases (lease_code, property_id, tenant_name, tenant_cnic, duration_months, monthly_rent, security_deposit, start_date) 
                          VALUES (?, ?, ?, ?, ?, ?, ?, CURDATE())");
    $ins->execute([$leaseCode, $propId, $tenant, $cnic, $months, $rent, $securityDeposit]);

    // 3. Mark property as Leased
    $upd = $pdo->prepare("UPDATE properties SET status = 'Leased' WHERE id = ?");
    $upd->execute([$propId]);

    $pdo->commit();

    echo json_encode([
        "status"           => "success",
        "lease_code"       => $leaseCode,
        "security_deposit" => number_format($securityDeposit, 2)
    ]);
} catch (Exception $e) {
    $pdo->rollBack();
    echo json_encode(["status" => "error", "message" => $e->getMessage()]);
}
?>
