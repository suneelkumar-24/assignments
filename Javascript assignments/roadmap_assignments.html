JavaScript Core Roadmap Assignments

Clone this repository to your laptop, open these files in your local text editor (e.g. VS Code), and practice implementing these 12 core tasks!

📍 Javascript Syllabus Covered in These Tasks

📤 Output Methods
console.log document.write alert prompt
📦 Variables
let var const
➗ Operators
Arithmetic (+ - * /) Assignment (= += -=) Comparison (== === > <)
🚦 Conditions & Logical
if / else / else-if && (AND) || (OR) ! (NOT)
Birth Year Finder Task 1
🎯 Objective

Ask the user for their Name and Age. Calculate their birth year and output the message.

📋 Requirements
  • Declare name and age variables using let.
  • Collect inputs using prompt() twice.
  • Calculate birth year using current year 2026: 2026 - age.
  • Display the result via alert() and console.log().
💻 Example Output
Alert & Console: "Hello Ali, you were born in 2002."
Simple Operations Print Task 2
🎯 Objective

Take two numbers from the user. Compute their sum, difference, and product, then print them directly on the webpage.

📋 Requirements
  • Use prompt() to request both numbers.
  • Use Number() function to convert string inputs to numbers.
  • Apply arithmetic operators: +, -, *.
  • Use document.write() to print the results.
💻 Example Output
Webpage: Sum: 15 Difference: 5 Product: 50
Voter Eligibility Checker Task 3
🎯 Objective

Verify if a user is eligible to vote. If not, calculate how many years they must wait.

📋 Requirements
  • Get user age via prompt().
  • Check age condition using if and else.
  • Use comparison operator >= 18.
  • Output the message using alert().
💻 Example Output
If age is 15: "Alert: You must wait 3 more years to vote."
Celsius to Fahrenheit Task 4
🎯 Objective

Convert temperature values. Prompt user for temp in Celsius, and convert it to Fahrenheit.

📋 Requirements
  • Store conversion constants (9/5 and 32) using const variables.
  • Apply arithmetic operations: *, /, +.
  • Log the output to the console.
💻 Example Output
If Celsius is 30: Console: "30°C is equal to 86°F."
Grade Calculator Task 5
🎯 Objective

Read a student's percentage score and display their grade.

📋 Requirements
  • Use if, else if, and else checks.
  • Grade Boundaries: A (>=90), B (>=80), C (>=70), F (Below 70).
  • Output the result using alert().
💻 Example Output
If score is 85: "Alert: Grade B"
Portal Gatekeeper Task 6
🎯 Objective

Validate credentials. Grant portal access only if both parameters are exact matches.

📋 Requirements
  • Get username and password from prompts.
  • Verify username matches "admin" AND password matches "pass123".
  • Must check both using logical AND &&.
  • Alert "Access Granted" or "Access Denied".
💻 Example Output
If correct: "Alert: Access Granted!" Otherwise: "Alert: Access Denied!"
Weekend Detector Task 7
🎯 Objective

Ask user for a day name. If it is Saturday or Sunday, inform them it's the weekend.

📋 Requirements
  • Verify if day is "Saturday" OR "Sunday".
  • Must use logical OR operator ||.
  • Compare using strict equality ===.
  • Log result to console.
💻 Example Output
If day is "Sunday": Console: "It's the weekend! Time to relax!"
Bill Discount Guard Task 8
🎯 Objective

Check if the user is spending enough to get a discount. If the bill is NOT less than $100, apply a $15 discount.

📋 Requirements
  • Set limit = 100 using const.
  • Verify condition using logical NOT operator !.
  • Subtract 15 using assignment operator -=.
  • Alert the final total.
💻 Example Output
If bill is 120: "Alert: Discount applied. Final total is: $105"
Ticket Pricing Advisor Task 9
🎯 Objective

Determine cinema ticket prices based on age and student status using nested conditions.

📋 Requirements
  • Ask for age and if they are a student ("yes"/"no").
  • Under 12: price is $5.
  • Ages 12-64: If student, price is $10; otherwise, price is $15 (requires nested if).
  • Ages 65+: price is $8.
  • Alert the ticket price.
💻 Example Output
If age is 20 and student is "yes": "Alert: Your ticket price is $10."

🎯 Objective

Determine if a user-supplied number is even or odd.

📋 Requirements
  • Collect a number using prompt().
  • Apply the modulus arithmetic operator % (checks remainder when divided by 2).
  • Use an if-else conditional block.
  • Print output message to console.log().
💻 Example Output

Number Guessing game Task 11
🎯 Objective

Store a secret number. Prompt the user to guess it and check if it's correct.

📋 Requirements
  • Set a constant secret number (e.g. 7) using const.
  • Ask the user to input a guess (1-10).
  • Check if guess matches secret. If correct, alert success.
  • Else, alert if the guess was too high or too low.
💻 Example Output
If secret is 7, and guess is 4: "Alert: Too low! Try again."
Electricity Bill Calculator Task 12
🎯 Objective

Compute total bill amount based on units consumed using a stepped price scale.

📋 Requirements
  • Prompt the user for units consumed.
  • Stepped rates:
    - First 100 units: $5 per unit.
    - Next 100 units (101-200): $8 per unit.
    - Above 200 units: $12 per unit.
  • Calculate total cost using arithmetic and assign value.
  • Alert the final bill amount.
💻 Example Output
If units consumed is 150: 100 units * $5 = $500 50 units * $8 = $400 Total: "Alert: Your total bill is $900."
