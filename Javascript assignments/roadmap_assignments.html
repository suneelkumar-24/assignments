Clone this repository to your laptop, open these files in your local text editor (e.g. VS Code), and practice implementing these 12 core tasks!

Birth Year Finder Task 1
🎯 Objective

Ask the user for their Name and Age. Calculate their birth year and output the message.

📋 Requirements
  • Declare name and age variables using let.
  • Collect inputs using prompt() twice.
  • Calculate birth year using current year 2026: 2026 - age.
  • Display the result via alert() and console.log().
💻 Example Output
Alert & Console: "Hello Ali, you were born in 2002."
